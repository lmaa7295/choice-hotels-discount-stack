The AAA deal is worth a closer look because the headline number (15%) hides restrictive terms. Based on Choice's current official AAA promotion terms:

That early check-out clause is the one that burns people. Book a two-night AAA rate, leave after one night, and you've paid more than if you'd booked the single night at the normal rate in the first place.
